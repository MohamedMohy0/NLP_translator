# NLP Translator 

A mini NLP project built using Python, NLTK, and Streamlit that translates text between languages after performing text preprocessing and cleaning.
The project also includes trained models saved as `.pkl` files for easy reuse without retraining.


##  Features

- Text preprocessing and cleaning using NLTK
- Language translation workflow
- Interactive GUI using Streamlit
- Saved trained models in `.pkl` format
- Easy-to-use interface
- Reusable trained models without retraining


##  Technologies Used

- Python
- NLTK
- Streamlit
- Pandas
- NumPy
- Pickle (.pkl)

##  Installation

Clone the repository:

git clone https://github.com/your-username/NLP_translator.git

Move into the project directory:

cd NLP_translator

Install dependencies:

pip install -r requirements.txt


##  Run the Application

streamlit run app.py


## Train the Model

python train_model.py

The trained models will automatically be saved as `.pkl` files.


##  Saved Models

The project stores:

- Trained NLP model
- Text vectorizer/tokenizer

This allows predictions without retraining every time.
